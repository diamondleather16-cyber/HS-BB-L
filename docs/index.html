連合チーム / Rating分配

連合そのものに恒久IDは持たせず、構成校それぞれの学校IDを保持。試合時Ratingは構成校Ratingの加重平均、試合のRating変動総量は構成比で分配します。

穴水・能登・鹿西 = 1/3 + 1/3 + 1/3 連合 +10.00 → 各校 +3.33 前後（合計 +10.00）
GitHub側の master/team_members.csv に team_label,school,weight を登録すると正式Rating計算に反映します。 weight空欄は均等配分です。

連合チーム / ID分解・紐づけ

連合IDは削除せず履歴用に凍結し、年度・季節・大会ごとに構成校の恒久school_idへ紐づけます。

流れ： 連合名を構成校IDへ紐づけ → 分配率確認 → 「分解・凍結」。 凍結後は通常の学校マスタから連合疑似IDを隠し、対戦台帳では当時表記を残します。

Rating履歴

試合ごとの試合前Rating・変動・試合後Ratingを確認します。

県以下の地域マスタ

県ごとの地域数は固定しません。必要に応じて追加・削除・改名できます。

代表区分マスタ

北海道・東京の通常2枠、記念大会の増枠県を学校の恒久地域とは別IDで管理します。

複数IDを統合

統合先IDを選び、各IDの対戦履歴と整合性を確認します。
