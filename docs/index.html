連合チーム / Rating分配

連合そのものに恒久IDは持たせず、構成校それぞれの学校IDを保持。試合時Ratingは構成校Ratingの加重平均、試合のRating変動総量は構成比で分配します。

穴水・能登・鹿西 = 1/3 + 1/3 + 1/3 連合 +10.00 → 各校 +3.33 前後（合計 +10.00）
GitHub側の master/team_members.csv に team_label,school,weight を登録すると正式Rating計算に反映します。 weight空欄は均等配分です。
