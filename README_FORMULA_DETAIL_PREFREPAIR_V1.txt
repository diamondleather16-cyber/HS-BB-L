2機能追加

1. Rating指数の拡大・根拠表示
- 対戦台帳の「指数」をクリック可能に変更。
- モーダルで実効Kの式を大きく表示。
- T/L/S/R/W/D/Iそれぞれの係数値と根拠を表示。
- 大会参加校数→大会レベル、階層、季節、地区特性/全国大会マッチ位置、
  両校の次勝利数、得失点差、イニングを確認可能。
- ΔR = K × (結果 - 期待値) まで数値で表示。

2. 県大会タグの一括補正
- 対戦台帳上部に「県タグ補正」追加。
- 県大会階層について、両校の学校マスタ所属県が同じなのに
  台帳のprefectureタグだけ違う試合を自動抽出。
- 「岩手↔宮城」「秋田↔山形」「岡山↔広島」「鳥取↔島根」
  「香川↔徳島」等の誤タグを一覧確認して一括補正可能。
- チェックボックスで対象を選択して1回のGitHub保存。
- match_edits_shared.json の override として保存するため元データを破壊しない。
- 保存後は既存のRating自動再計算対象。

安全:
school_master_shared.json / match_edits_shared.json 等のライブデータはZIPに含めない。
