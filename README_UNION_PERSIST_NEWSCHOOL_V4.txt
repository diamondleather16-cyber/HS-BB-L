連合 persistence + 学校新規登録 V4

1. 連合ON後のページ更新で連合マスタから消える問題
- unionTeamsをGitHub保存待ちだけでなく localStorage に即時保存。
- ページ更新時は GitHub側 unions とローカル未反映 unions を union_id でマージ。
- 連合ON直後に更新しても、連合マスタに残る。
- pagehideでもunionTeamsを保存。

2. 連合構成校が学校マスタにない場合
- 構成校検索候補の末尾に「この名前を学校マスタへ新規登録」を追加。
- 連合編集画面にも「学校マスタ新規登録」ボタンを追加。
- 学校名・地区・都道府県・県内地区・フリガナを入力して新規school_idを発行。
- 保存後、そのまま連合構成校として選択可能。
- 検索自体は引き続き学校名(canonical_name)だけを対象とする。
