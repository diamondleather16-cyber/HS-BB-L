# Historical compatibility archive (2000+)

ここには2000年春以降の地区大会・全国大会の試合CSVを追加します。
通常台帳と同じ列でOKです。`build_prefecture_model.py` はこのフォルダ以下のCSVを
県相性の長期母集団だけに使用し、県Rating本体へは直接加算しません。

古い試合は年次減衰:
- 2000-2005: 0.30
- 2006-2010: 0.40
- 2011-2015: 0.55
- 2016-2020: 0.75
- 2021-: 1.00

実データは未同梱です。収集したCSVをここへ配置してください。
