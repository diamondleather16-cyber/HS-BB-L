学校マスタ 県別カラーバー v1

変更:
- 学校マスタの「ID索引」を削除
- ID欄の地区ID/県ID/地区内IDの分解表示を削除
  → 恒久school_idだけ表示
  → 地区/県/地域は各専用列で人間向け名称表示
- 学校マスタの各行（バー全体）を県別に着色
- 9地区ごとに基本色を持ち、その地区内の県は近い色相で変化
- 北海道・東京で代表区分が設定されている学校は
  北北海道/南北海道、東東京/西東京を近似色で分ける

色系統:
- 北海道: 黄
- 東北: 青
- 関東・東京: 緑
- 北信越: 紫
- 東海: オレンジ
- 近畿: 赤～ピンク
- 中国: 青緑
- 四国: 黄緑
- 九州: 赤紫

全県に個別色を割当。
色は淡色にして文字・ボタンの可読性を優先。
県色そのものを学校IDには含めない。

注意:
北海道/東京の北南・東西色は representative_area が学校に設定されている場合に使用。
代表区分が未設定なら北海道/東京の基本県色。
