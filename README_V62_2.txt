V62.2 京都県名正規化バグ修正

症状
- 県Ratingで京都が「京」と表示される。
- 「京都」で検索すると別扱いの1000 / 履歴なし行が出る。
- 「京」と「京都」が別県のように分裂していた。

原因
build_prefecture_model.py の県名正規化が
  base.replace("都","").replace("府","").replace("県","")
となっており、「京都」の内部文字「都」まで削除していた。

修正
- 行政区分の除去は末尾の「府」「県」だけに限定。
- 東京/東東京/西東京、北海道/北北海道/南北海道の既存特例は維持。
- 京都 -> 京都、京都府 -> 京都、大阪府 -> 大阪、石川県 -> 石川。
- regression guardを追加。
- UI側でも古い生成CSVの「京」は一時的に「京都」と表示する防御を追加。
- Rating workflow再計算後は出力自体が「京都」に統一される。

V62.1の歴史監査、V62の2000-2016補完、V61.3までの台帳安定化を継承。
