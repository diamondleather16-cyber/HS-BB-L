V53 Wikipedia 選抜ブラケット対応

症状:
第88回選抜(2016)はWikipedia上で31試合だが、
V52の大会取込UIは決勝1試合しか取得できなかった。

原因:
夏のWikipediaは「試合日/勝利/スコア/敗戦」形式の結果表がある一方、
選抜の多くは1回戦～準決勝をブラケット表だけで掲載している。

V53:
- MediaWikiブラケットのrowspan/colspanを座標展開。
- 1回戦/2回戦/3回戦/準々決勝/準決勝ごとの列を認識。
- 各ラウンド列で学校+得点を上下2校ずつ組にして試合へ復元。
- 各試合に最寄りの日付セルを付与。
- 日付セルの「延長10回/11回/12回」も innings / finish_type に反映。
- x/×付きサヨナラ得点を認識。
- 決勝イニング表は10回以降の列まで見て延長回数を自動取得。
- Wikipedia記載の試合数と抽出数を照合。

第88回選抜の目標:
31試合 = 1回戦16 + 2回戦8 + 準々決勝4 + 準決勝2 + 決勝1。

V50以降の県Rating・県相性・学校相性の歴史データ反映は継承。
