V7 まとめ修正

1. 大会取込
- 県大会以下のみ都道府県必須。
- 地区大会は「地区」を選択し、都道府県は不要。
- 全国大会は都道府県不要で「全国」として保存。
- Nationalのような擬似県は作らない。

2. 県選択順
- MASTER_PREFECTURESと主要な県セレクタを北→南の高校野球順へ統一。
- 元データの出現順で愛知などから始まるセレクタも順序補正。

3. 対戦台帳CSV
- innings / finish_type を独立列として書き出し。
- 再取込時に note の「7回コールド」「延長10回」と同期。

4. 連合マスタ
- 「未設定連合を自動推定」を追加。
- 連合表示名を ・ / + / ／ / 、 等で分割。
- 同県学校マスタから完全一致候補を探し、一意なら構成校へ自動投入。
- 完全に揃えばactive、一部だけならdraftのまま手確認。

5. 学校相性
- 新タブ「学校相性」を追加。
- school_idを優先して複数回対戦カードを抽出。
- 対戦数・勝敗・得失点・現在Rating期待勝率との差を表示。
- 相性差は少数対戦を強く出し過ぎないよう n/(n+6) で縮小。
- 現時点では分析表示のみでRating本体には加算しない。

6. 2000年以降データ
- 県大会も抽出対象とする方針。
- 県相性には従来通り地区大会・全国大会のみ使用。
- 県大会は将来の学校間相性母数として利用。

7. 大会シミュレータ
- 新タブ「大会シミュレータ」を追加。
- 2/4/8/16/32校。
- 参加順が櫓順。↑↓で手修正可能。
- 現在Rating、開催県ホーム補正、甲子園経験補正、ラウンド間隔/休養補正。
- 初戦日から各ラウンド日と「中N日」を表示。
- 1,000〜100,000回試行し優勝率順位予想を表示。
- 1回の世界線ではスコア付き試合経過を表示。

既存V6までの大会置換、世代交代監査、予選偏り監査、県タグ揺れ補正、連合永続化等は維持。
