夏→秋 世代交代 65%持越し補正

各学校について、その年度の最初の秋公式戦の直前に1回だけ適用。

秋開始Rating = 1000 + (補正前Rating - 1000) × 0.65

例:
1200 → 1130
1150 → 1097.5
1100 → 1065
1050 → 1032.5
1000 → 1000
950 → 967.5
900 → 935
800 → 870

仕様:
- 春→夏には適用しない。
- 秋の最初の公式戦の直前に適用。
- jinguも秋世代扱い。ただし通常は県秋・地区秋で既に補正済み。
- 連合チームの場合も構成校ごとに、その年度1回だけ補正。
- Rating履歴に「世代交代 65%持越し」としてイベントを残す。
- 補正後Ratingを基準に、その秋初戦の期待勝率とRating変動を計算する。
- school_id分岐後もschool_id単位のRating系列で適用される。

生データ（school_master_shared.json / match_edits_shared.json等）はZIPに含めない。
