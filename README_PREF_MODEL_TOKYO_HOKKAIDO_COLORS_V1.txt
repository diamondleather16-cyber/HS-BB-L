次回修整7項目 統合版

1) 県相性マスタ再計算
- 県外公式戦から県ペア相性Eloを逐次更新。
- 少数対戦は n/(n+8) で0方向へ縮小。
- 石川-富山等も実績に応じて0以外になり得る。

2) 県Rating正式時系列Elo
- 基礎K=8。
- 異なる県Rating単位同士の公式戦のみ更新。
- output/prefecture_ratings.csv
- output/prefecture_rating_events.csv
- 2017-2024終了時点を学校Rating用historical priorとして固定。

3) 学校Rating期待値へ県要素
期待値用Rating =
  学校Rating
  + clamp(0.25*(県Rating-1000), ±15)
  + clamp(0.50*県相性, ±15)
試合後のRating変動本体は学校Ratingのみ。

4) 北海道・東京
計算内部は北北海道/南北海道、東東京/西東京を独立単位。
春秋は画面表示のみ北海道/東京へ統合。
南北・東西同士の対戦では差を反映し県Ratingも更新。
同一区分同士は県要素が実質相殺。

5) 大会階層
北海道:
 春秋 支庁/支部=県大会、全道=地区大会、夏南北=県大会。
東京:
 春 一次=地区予選、都大会=県大会。
 夏 東西=県大会。
 秋 一次+都大会R32まで=県大会、R16以降=地区大会。

6) 対戦台帳の県表示/絞込
学校マスタ所属県/代表区分を優先した実効県に変更。
春秋の北海道/東京は表示統合、夏は南北/東西表示。

7) 配色・県Rating画面
B案の落ち着いたグラデーション配色。
北海道=紫、東北=青、関東=緑、東京=青緑、
北信越=黄緑、東海=黄土、近畿=橙、中国=茶、
四国=桃、九州沖縄=臙脂。
内部49代表区分はすべて別色。
県Ratingカード、比較カード、履歴線、相性散布図に流用。

- イニング誤認修正
- 指数詳細
- 県タグ一括補正
