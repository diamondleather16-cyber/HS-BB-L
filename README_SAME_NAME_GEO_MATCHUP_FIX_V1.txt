修正内容

1. 県相性が0.0になる表示不具合
- Python側の県ペア順序とブラウザlocaleCompare順序が一致しないケースを修正。
- A→B / B→A の両方向で相性マスタを検索し、向きに応じて値を入れ替える。
- 石川/富山のようなペアも正しく表示。

2. 同名校の別県混入
例: 石川県の「飯田」と長野県の「飯田」。
- raw校名だけでグローバルaliasを適用しない。
- school_id / 試合別紐づけを最優先。
- 次に team1_prefecture/team2_prefecture、note内team*_pref、
  県大会階層ならrow.prefectureを使って同名候補を県で判別。
- 県が一致する候補が一意なら、そのschool_idへ自動解決。
- 同名候補が複数で県ヒントがない場合は、誤った学校へ自動統合せず未解決のまま残す。
- フロント表示、学校Rating計算、県Rating計算の3箇所を同じ考え方へ統一。

これにより、長野県大会の「飯田」が石川の飯田の履歴・Ratingへ混入する問題を防ぐ。

既存の削除機能、県Rating、東京/北海道ルール、配色、65%世代交代等は維持。
ライブ共有JSONはZIPに含めない。
