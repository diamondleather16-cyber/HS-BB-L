試合別 school_id 反映修正 v2

症状:
- 試合別紐づけ自体は保存されているのに、対戦台帳の大きな学校名表示が変わらない
- 学校詳細の「対戦履歴」が0件のまま
- Rating履歴だけ新しい学校へ移り、対戦履歴と食い違う
- 同じ raw 名「金沢」が global alias の影響を受ける

原因:
match-specific team_links は Rating builder では優先されていたが、
Pages の表示・学校詳細・検索の一部がまだ raw team / global alias を見ていた。

修正:
- Pagesでも match-specific school_id/canonical を最優先する単一resolverを追加
- 対戦台帳の表示名も試合別紐づけ先へ変更
- 学校詳細の対戦履歴を school_id ベースで集計
- 対戦相手名も試合別IDで解決
- 台帳検索・並び順・ブラウザfallback Ratingも試合別IDを尊重
- 将来の分離時、金沢（神奈川）（石川）のような二重県サフィックスを作らない
  例: 元が金沢（神奈川）でも石川分離の候補名は金沢（石川）

注意:
すでに作成済みの「金沢（神奈川）（石川）」という表示名そのものは自動改名しません。
学校マスタ編集で「金沢（石川）」へ一度直せば、そのschool_idを維持したまま表示だけ整えられます。
