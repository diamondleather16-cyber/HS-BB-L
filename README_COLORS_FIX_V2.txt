- 色が淡すぎて白に近かった
- 以前のlocalStorage学校マスタに県が空欄/旧表記の学校があると白になった

4. 青森県→青森、大阪府→大阪、東京都→東京のように正規化
5. 県欄に同系色の丸印も表示
6. app/cssを app-colors-v2.js / styles-colors-v2.css に変更してキャッシュ回避
7. 上部の確認タグは UI-COLORS-V2
8. node --check済み
