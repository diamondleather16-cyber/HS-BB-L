V36 同名校・他県aliasの紐づけ修正

対象:
徳島県内の「城西」が「城西大城西」へ紐づいており、修正できないケース。

原因:
「城西」は城西大城西のaliasとして既に存在するため、
徳島の新規学校を canonical_name=城西 で作ると、
global alias resolver が再び城西大城西を優先する余地があった。

V36:
- 同名/alias衝突がある場合、徳島側は内部canonicalを
  「城西（徳島）」として作成する。
- raw試合名は「城西」のまま。
- aliases=["城西"] として徳島県内の試合では県情報で正しく解決。
- 既に城西大城西へ試合別紐づけされている場合、
  紐づけ画面に
  「徳島の『城西』として分離・紐づけ」
  ボタンを表示。
- ボタン1回で学校作成（既存なら再利用）→学校マスタ保存→
  その試合のteam_link上書きまで行う。
- 県取得はrow.prefecture直読みにせずsidePrefHintを使用。
