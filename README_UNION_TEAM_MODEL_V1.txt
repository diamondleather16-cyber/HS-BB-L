連合チーム正式管理 V1

- 学校マスタは実在校だけを管理。連合は連合マスタへ。
- 連合は年度・季節・大会ごとに別union_id。
- 構成校は学校マスタschool_idを複数指定。比率なしなら均等配分。
- 対戦台帳はteam1/team2ごとに通常校/連合を切替し、union_idを選択。
- 台帳一覧は「連」バッジ、連合のみ/通常校のみフィルタ。
- Ratingは連合の構成校Rating加重平均で試合し、変動を構成比で構成校へ分配。
- union_id優先なので同名連合でも大会違いを混同しない。
- 既存学校マスタ内の旧連合は安全のため自動削除しない。連合マスタ登録→台帳紐付け確認→旧学校レコード削除の順で移行。
