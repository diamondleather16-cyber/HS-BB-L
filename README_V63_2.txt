V63.2 一括取込 登録前メタデータ編集

目的
- 一括解析の自動判定が揺れても、50件を個別画面で直す必要をなくす。
- 一括登録直前の一覧で大会情報を確認・編集する。

追加
- 各大会カードで登録前に直接編集:
  年 / 季節 / 都道府県 / 階層 / 地区 / 大会名
- 共通一括操作:
  全件の年 / 季節 / 階層をまとめて変更
- 「大会名を統一規則で再生成」ボタン
  例: 2021秋・石川・県大会 -> 秋季北信越石川2021
- 一括登録時、画面上で編集したmetadata_overridesをActionsへ送信。
- backendが各試合のyear/season/region/prefecture/tournament/levelを書き直してからCSV登録。
- 必須項目未設定は登録前に停止。
- 個別試合確認へ移動して戻っても未登録の大会情報編集をlocalStorageで保持。

誤判定低減
- 神宮/選抜/選手権の判定をページ本文全体ではなくtitle/H1中心に変更。
  koshien89本文やナビの「明治神宮」で全件神宮扱いになる問題を抑制。

継承
- V63.1 一括解析結果待ち修正
- 最大120URL / 最大4並列解析 / 成功分一括登録
- V62.2までのRating/県名修正
