HS-BB-L UI Preview v6

今回の追加:
- スマホ表示を強化
- 学校マスタで複数IDをチェック選択
- 2校以上を一括統合
- 統合先IDを選択可能
- 選択した各IDの対戦履歴を並べて比較
- 重複試合 / スコア差異 / 地区不一致 / 県不一致を統合前に表示
- 統合後は即座にランキング計算へ反映
- 統合状態はブラウザlocalStorageへ保存
- 同じ端末・同じブラウザでは再訪しても保持
- 学校マスタのソート:
  学校ID / 地区ID / 県ID / 県内地区ID / フリガナ / 学校名
- 地区ID・県IDの索引チップから該当位置へジャンプ
- 学校IDを 地区ID / 県ID / 県内地区ID に分解表示

重要:
このv6は「UI上で実際に統合して使用感を確認する」段階。
GitHub上のmaster CSVそのものへの書き込みはまだ行わないため、
PCとスマホの統合状態は自動同期されない。
CSV書き出し/読込で移行できる。
正式運用ではGitHub側masterを唯一の正本にする予定。
