V41 3点修正: 連合自動解析高速化 / ページ軽量化 / 東京同名校誤判定

1. 連合マスタ自動解析
- 従来: 構成校名1個ごとに学校マスタ全件を走査。
- V41: 既存の schoolNameCandidateMap を使用し、名前から候補を直接取得。
- 県条件もindex取得後に絞る。
- 40連合ごとにrequestAnimationFrameでUIへ制御を返し、解析中も固まりにくくした。
- 解析後の不要な学校マスタ全表再描画を廃止。

2. ページ全体の重さ
- effectiveMatchSchool が実質毎回再計算されていたため、WeakMapキャッシュを実装。
- identity index再構築時に全行のteam1/team2解決結果をキャッシュ。
- 紐づけ・マスタ変更時だけキャッシュ破棄。
- 台帳/学校/連合テーブルの画面外行に content-visibility:auto を適用し描画負荷を軽減。

3. まだ残っていた東京の城西誤表示
- 東東京/西東京はidentity判定では東京として同一扱い。
- 北北海道/南北海道も北海道として同一扱い。
- 秋季東京地区大会など、Rating上regionalでも実質東京都内だけの大会は
  row prefecture=東京を同名校解決の地理ヒントに使用。
- これで「誤紐づけ無効: 東京→東京」の矛盾表示を防ぐ。
- 東京地区大会の「城西」が徳島の城西へ流れるのも防止。

Rating計算式・データ形式は変更なし。
