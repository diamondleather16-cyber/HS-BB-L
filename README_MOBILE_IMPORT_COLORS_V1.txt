v1: 色統一 + スマホURL大会取込

色:
- ランキングの各学校行を学校マスタと同じ県色で全面塗りつぶし
- 両画面とも school_master_shared.json の prefecture を最優先
- ID分岐時は元校の県内地区/代表区分をクリアして旧色継承を防止
- 北海道/東京だけ恒久的な代表区分色を許可

大会取込:
- ページに「大会取込」タブ追加
- 年/季節/県/階層/URLをスマホから登録
- GitHub ActionsがURLを取得してHTMLテーブル/簡易テキスト形式を解析
- 解析結果は本番投入前にページで確認
- 「この内容で登録」で data/imported/<year>/<season>/<県>.csv へ追記
- 重複キーは追記しない
- data/** 更新でRating workflowが自動起動

注意:
- v1はHTML結果ページを対象。PDF自動解析はまだ対象外。
- 自動解析は必ずプレビュー確認後に承認する安全設計。
