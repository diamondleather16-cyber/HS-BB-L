表記揺れ紐づけ + GitHub共有保存安定化 v1

1. 京都/島根など未着色対策
- 都道府県表記をより強く正規化
- 京都府 / 京都府大会 / 島根県 / 島根県大会のような値でも県色を取得
- 他47都道府県にも同じ正規化を適用

2. 対戦台帳 → 現在の学校へ紐づけ
- チーム名の下に「紐づけ」ボタン
- クリックして現在の学校を検索・選択
- 旧表記を選択校のaliasesへ追加
- 旧表記が暫定の独立学校として存在する場合は merged + successor_id を付与
- 明示aliasを暫定canonicalより優先して解決
- 対戦台帳に「元表記 → 現在校」を表示
- GitHub同期ONならその場で共有マスタへ保存
- Rating正式反映は Build Rating Events v2 & Deploy 実行後

3. スマホGitHub共有保存対策
- Token中の空白/改行を自動除去
- PC/スマホ同時更新など GitHub 409/422 時に最新SHAを取り直して1回自動再試行
- 失敗ダイアログに確認項目を表示

注意:
2017-2024層は現行Ratingモデルでは個別試合Eloではなく歴史prior層。
この紐づけは台帳表示とalias正本には効くが、2017-2024全試合を個別Eloとして
現Ratingへ流し込む変更ではない。2025以降のRatingイベントはalias反映対象。
