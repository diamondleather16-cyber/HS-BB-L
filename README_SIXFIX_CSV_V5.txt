6点修正 + 対戦台帳CSV V5

1. 大会再取込の倍増対策
- 大会取込に「同じ大会を置換 / 追加」を追加。置換をデフォルト。
- 置換は data/imported の同一大会名を一度外して新しい解析結果へ差替え。
- 旧/新で対戦校ペアが一意に対応する場合、match_edits の edit_key を新試合へ移行。
- 回戦・日付・スコア修正で別試合化して倍増する問題を抑止。

2. 世代交代65%監査
- 学校マスタ上部に「世代交代監査」。
- 夏最終 / 現在の世代交代 / 秋初戦を比較。
- 要修正を学校単位または一括で「秋初戦直前」にアンカー固定。
- generation_reset_overrides を match_edits_shared.json で共有。

3. 県以下・予選試合数偏り監査
- 「予選偏り監査」で県以下試合数・ΔR合計・1試合平均を表示。
- 長野等の予選試合数差を先に実測する段階。
- V係数は未承認なので、この版ではRating計算本体へまだ適用しない。

4. 2000年以降の長期県相性レイヤー
- data/historical_compat/**/*.csv を自動読込。
- 地区大会 / 全国大会だけ県相性へ反映。
- 古い試合は 0.30 / 0.40 / 0.55 / 0.75 / 1.00 で減衰。
- 県Rating本体には直接加算しない。
- 実試合データ自体は未同梱。今後収集したCSVを置くだけで反映。

5. 連合チーム
- V4までの大会単位union_id、台帳インラインON、ページ更新保持、新規構成校登録を維持。

6. 旧連合学校レコード整理
- 連合マスタに存在する表示名と同名の旧学校レコードを安全確認後に学校マスタから除外。
- 構成校として使われているschool_idは対象外。
- tombstoneを残して再生成を防止。

追加: 対戦台帳CSV
- 現在の台帳フィルタ結果をCSV書き出し。
- CSVをExcel等で直接編集して取込可能。
- edit_keyが一致する行は更新、edit_keyなし/不一致は新規手入力行として追加。
- CSVから行を削除しても自動削除はしない（事故防止）。
