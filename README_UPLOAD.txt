GitHub Webアップロード専用 v2

アップロード先:
HS-BB-L / docs /

必ず3ファイルすべてアップロード:
- index.html
- styles.css
- app.js

手順:
1. GitHub → HS-BB-L → Code
2. docs フォルダを開く
3. Add file → Upload files
4. 上の3ファイルをまとめて選ぶ
5. Commit changes
6. Pages/Deploy を実行
7. Safariでページを再読込

反映確認:
ページタイトル横に「mobile-edit-fix-2」と出れば最新版です。

編集方法:
学校マスタ → 各学校の「編集」ボタン →
地区/都道府県はプルダウン選択 → この内容で保存。
保存後「保存しました：学校名」と表示されます。
