V63 過去大会 一括URL取込

目的
- koshien89等から過去大会を1URLずつ解析する作業を大幅に短縮。
- 49地区×春夏秋、地区大会など大量URLをまとめて処理する。

機能
1. 複数URL一括解析
- 1行1URLで最大120件。
- GitHubへの依頼は1ファイルだけ。
- Actions内で最大4URLずつ並列解析。
- ページタイトル/本文から年・季節・県/地区・大会名を自動推定。
- 既存フォームの値は自動判定できない場合のfallback。

2. 一覧ページ自動展開
- koshien89のカテゴリ/一覧ページ等を1URL指定。
- blog-entryリンクを最大120件抽出。
- 抽出した大会URLを4並列解析。
- Wikipedia一覧の場合も/wiki/リンクを対象。

3. 一括結果画面
- 大会ごとに 成功/エラー/試合数 を一覧表示。
- 「確認」で従来の試合単位編集画面へ入れる。
- 成功分は「一括登録」でまとめて本番CSVへ登録可能。
- 個別修正が必要な大会だけ従来どおり個別登録できる。

4. 安全性
- 解析だけを並列化し、CSVへの書込は逐次処理。
- workflow timeoutを15分へ延長。
- 最大並列数4、最大URL120。
- replaceモードは大会名単位で置換する既存仕様を維持。
