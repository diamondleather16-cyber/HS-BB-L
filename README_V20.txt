V20 保存済み誤表示・遅延キュー消失修正

症状:
「保存済み」を待って更新したのに、一部だけ保存前へ戻る。

根本原因:
V19には古い3秒遅延の queueMatchEditsSave が残っていた。
ある変更がタイマー待ちのまま、別の即時保存バッチが完了すると、
キューが空だと判断して
  - pendingを削除
  - 「すべて保存済み」を表示
していた。
その直後に更新すると、タイマー待ちだった変更だけ消えた。

V20:
- 対戦台帳の全保存を即座に同一キューへ登録。3秒遅延を廃止。
- 各保存操作に連番(seq)を付与。
- GitHubで確定した最大seqを記録。
- queued=0だけでは保存済みにしない。
- committed seq >= latest seq を満たした時だけ「保存済み」表示。
- 途中の保存が完了しても新しい操作があればpendingを削除しない。
- 学校マスタ側の「保存済み」が対戦台帳保存中表示を上書きしない。

  対戦台帳：保存済み #NN
が出た時点で、その時点までの対戦台帳変更がGitHub照合済み。
