V15 対戦台帳・紐づけ永続化

原因:
- 一部の「紐づけ」「履歴ID移動」「連合ON/OFF」はまだ3秒遅延queue保存だった。
- 即時保存のGitHub照合も overrides / manual_matches だけで、team_linksを検証していなかった。
- 保存後の team_links インデックス再構築も不足。

修正:
- team_linksをGit blob上で項目照合。
- 試合別「紐づけ」は保存完了まで待つ。
- 編集画面の現在校1/2も紐づけ保存を照合。
- 学校マスタの履歴ID移動も即時保存・照合。
- 連合ON/OFFも即時保存。
- 削除も遅延保存を廃止。
- 保存成功後matchTeamLinkMapを再構築。

「保存済み」「保存・照合しました」と表示された変更は、更新後も残ることを基準とする。
