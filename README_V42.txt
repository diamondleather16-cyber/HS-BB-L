V42 誤統合した別名を独立校へ戻す

対象例:
「産業技術高専 / 産技高専」が誤って「農産」の別名として統合され、
台帳で農産として解決されるケース。

学校詳細画面に「誤統合を戻す」を追加。

手順:
1. 誤統合先（例: 農産）の学校詳細を開く。
2. 別名一覧から「産技高専」等を選ぶ。
3. 「選択した別名を独立校へ戻す」。
4. 正式表示名・都道府県を確認。
5. 対象raw表記の全試合を新しい学校IDへ試合別リンク。
6. 誤統合先のaliasesからその別名を削除。
7. 学校マスタと対戦台帳リンクをGitHubへ保存。

既に同名の正規学校IDが存在する場合は、新規作成せず既存IDへ戻す。

この修正はRating計算式を変更しない。Ratingは保存後の再計算で追随する。
