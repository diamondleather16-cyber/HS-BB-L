連合インライン登録 V2

変更:
- 対戦台帳一覧の各チーム欄に「連合」ON/OFFスイッチ。
- 編集画面を開かず、その場で連合指定可能。
- ON時に 年度 + 季節 + 大会 + 県 + 台帳表示名 で既存連合を検索。
- 同一条件の連合があれば自動で同じunion_idへ紐付け。
- なければ連合マスタへdraft連合を自動作成し、その試合へunion_idを自動設定。
- 構成校未設定はオレンジの「連合ON」/「構成校未設定」表示。
- 連合マスタであとから構成校を設定。
- OFF時は試合の連合指定だけ解除。連合マスタ自体は他試合利用の可能性があるため自動削除しない。

Rating安全策:
- 連合ONは古いschool_id/canonical紐づけより優先。
- 構成校未設定の連合試合は、普通校として誤RatingしないようRating計算から一時除外。
- 構成校登録後の再計算で正しく構成校へ分配。

既存機能・共有JSONは維持。ライブ共有JSONはZIPに含めません。
