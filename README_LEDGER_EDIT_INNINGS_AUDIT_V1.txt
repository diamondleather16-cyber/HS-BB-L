統合改修 v1

1) 同一ID・複数県監査
- 学校マスタ/対戦台帳をschool_idで監査
- level=prefectureで同一school_idが2県以上 → 要確認
- 「台帳で確認」
- 「この県を新IDへ分離」
  県大会分は新IDへ一括match-specific link
  地区/全国は各試合の編集画面から手動リンク

2) 対戦台帳 手入力
- 「＋ 試合を手入力」
- GitHub master/match_edits_shared.json に保存
- Actionがoutput/all_matches.csvへ追加
- 約45秒デバウンス後Rating自動再計算

3) 山梨着色
- 関東・東京系の県色を追加
- 県コード/地区判定も山梨対応

4) 延長/コールドRating係数
5回C=1.08 / 6回C=1.06 / 7回C=1.04 / 8回C=1.02
9回=1.00
延長10=0.98 / 11=0.96 / 12=0.94 / 13=0.92 / 14=0.90
以後1回ごと-0.02、下限0.80
タイブレーク独自係数なし。実際の終了回だけで補正。
係数は最終K（Rating変動量）へ乗算。

5) 台帳編集
- 日付/大会/回戦/県/地区/得点/終了回/決着種別/URL/備考を編集
- team1/team2ごとに「現在校」をmatch-specificで紐づけ可能
- 同名別校（金沢など）を大会単位/試合単位で分離可能
- GitHub共有保存、PC/スマホ共通
- match_edits_shared.json更新でもRating Action自動起動

既存noteに「5回コールド」「延長11回」などがあれば自動抽出。
漏れは台帳編集から手入力。
