V37 台帳紐づけ表示反映 + 候補検索改善

1) 紐づけ保存済みでも台帳表示が元の学校名のまま
- 台帳セルの一部が raw team1/team2 を直接表示していた。
- team_linksで解決した学校名を優先表示するよう変更。
- 元表記と異なる場合は「元表記：○○」を小さく併記。
- 保存前後でidentity indexを明示的に再構築して即時再描画。

2) 「東」のような短い検索で候補が多すぎる
- 試合と同じ県を最優先。
- 完全一致 → 前方一致 → 部分一致。
- 同県に完全一致があれば、その候補だけ表示。
- 1文字検索は同県候補がある場合、他県候補を出さない。
- 1文字検索の候補上限12件。

学校ID/Rating計算式は変更なし。
