HS-BB-L V64.4 summary

1. 手入力試合の「更新すると消える」問題を修正。
   - GitHub保存済みのmatch_edits_shared.jsonを、トークン未保持時でも公開GitHub mainから直接再読込。
   - GitHub Pages側のdata反映が遅れていても、同一端末の永続ミラーを併用して試合を消さない。

2. GitHub保存済みデータのローカル永続ミラーを追加。
   - 保存待ちだけでなく、保存・照合完了後もmirrorを保持。
   - Pages/outputの生成待ち時間にリロードしても手入力試合を維持。

3. 手入力保存時のGitHub照合表示を強化。
   - master/match_edits_shared.jsonへの保存後、保存コミットを再読込してmanual_idの存在を照合。
   - 成功時は画面に「GitHub保存・照合済み（commit XXXXXXX）」を表示。
   - これが出なければGitHub保存完了扱いにしない。

4. 読込優先順位を整理。
   ① 認証済みGitHub main
   ② 公開GitHub raw main（トークンなしでも取得）
   ③ GitHub Pages data
   ④ 同一端末永続ミラー
   ※各段階で新しい編集をマージする。
