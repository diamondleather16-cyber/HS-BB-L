V39 対戦台帳 同名校表示・検索・行高整理

1. 台帳の主表示を紐づけ先に変更
   - team1/team2のraw名ではなくeffective school identityを主表示。
   - 連合だけは従来通り連合表示名。
   - 城西（徳島）などの試合別紐づけが、主表示そのものへ反映される。

2. 注釈を1行に統合
   - 旧: 試合別 / 元表記 / →正規校 が複数行に増えることがあった。
   - 新: 「試合別：城西→城西（徳島）」など1行のみ。
   - 長い場合は省略記号、全文はtitleで確認。

3. 行高を64pxに統一
   - 注釈の有無で行の高さがバラバラにならない。
   - team cell metadataは1行・ellipsis。

4. 同名校検索を県+school_idで絞る
   - 県フィルタを選択し、学校検索がその県の学校名/aliasに完全一致した場合、
     raw文字列ではなくschool_idで絞る。
   - 徳島+城西、大阪+東、愛知+瀬戸などを別県同名校から分離。
   - 県未選択時は従来通り横断検索。

Rating計算式・学校ID生成ルールは変更なし。
