連合チーム編集 v2 - 学校マスタ内編集方式

変更理由:
専用「連合チーム」タブは、全連合候補 × 4,000校超の選択肢を一度に描画し、
クリック時にブラウザが重くなる問題があった。

新方式:
- 専用タブを廃止
- 学校マスタで「連合」表示の学校を開く
- その編集画面の下部に「連合チーム ID分解」を表示
- その連合名が実際に出場した 年度/季節/大会 だけを表示
- 各大会ごとに構成校を既存 school_id へ紐づけ
- 構成比(weight)編集
- 「この大会の連合IDを分解・凍結」
- 同一連合名の別大会へ最初の構成をコピー可能
- 凍結しても連合IDは削除せず履歴保持
- 対戦台帳の当時表記は残し、その下に構成校を表示

対戦台帳との紐づけ:
キー = year + season + tournament + team_label
そのため、同じ連合名でも大会ごとに違う構成を持てる。

正式Rating:
ブラウザで整理後に tournament_teams.csv / tournament_team_members.csv を
GitHub master/ へ反映すれば、backend Rating計算は大会別構成を優先する。
