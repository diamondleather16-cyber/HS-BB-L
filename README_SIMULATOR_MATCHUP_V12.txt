V12

1. 大会シミュレータ高速化
- 大量試行中のDOM参照、schoolEvents検索、Rating検索を毎試合行わず、開始時にキャッシュ。
- 既定試行回数を1000回へ変更。
- 4校以上でも軽くなるよう一括試行を高速化。

2. 1ラウンドずつモード
- 「1ラウンド進める」を追加。
- 初戦→QF→SF→Fを1段ずつ実行し、勝者を次段の櫓へ反映。
- 「ステップをリセット」で同じ櫓からやり直し。

3. 色
- シミュレータの学校カードを既存の県色で表示。
- 学校相性画面も両校を県色付きピル表示。
- Rating反映対象（3試合以上）も表示。

4. 学校相性をRatingへ反映
- 学校vs学校の同一カードについて「過去3試合以上」がある場合のみ、4戦目以降に作用。
- Rating＋県補正で得た期待勝率と、過去直接対決の実績との差を利用。
- n/(n+6)で縮小し、さらに0.15倍。
- 最終的な期待勝率補正は最大±2.5ポイント。
- 連合戦には学校相性補正を適用しない。
- rating_events.csv に team1_expected_base / school_matchup_prior_games /
  school_matchup_residual / school_matchup_bias_prob を記録。
