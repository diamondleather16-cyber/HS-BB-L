対戦台帳 紐づけの試合単位化 v1

修正理由:
従来の対戦台帳「紐づけ」は raw 表記（例: 金沢）を学校マスタのグローバルaliasへ登録していた。
そのため石川決勝の「金沢」を直すと、神奈川県大会の「金沢」まで同じ学校へ引っ張られた。

修正:
- 対戦台帳の「紐づけ」は edit_key + team1/team2 単位の match-specific link に変更。
- master/match_edits_shared.json の team_links に保存。
- 同じ raw 表記の他試合には一切影響しない。
- 「学校マスタの別名」は従来どおり全試合共通の表記揺れ用。
- UIに「試合別」「全体別名」を区別して表示。
- Rating builder は既に team1_canonical/team2_canonical を優先するため、そのまま再計算へ反映。

金沢の例:
2026石川決勝: 金沢 -> 金沢（石川）
2026神奈川2回戦: 金沢 -> 金沢（神奈川）
を独立して保持できる。
