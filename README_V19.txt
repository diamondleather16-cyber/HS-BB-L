V19 対戦台帳 保存キュー化

症状:
連合ON/OFF、紐づけ、試合編集を続けて行うと
「既存の保存処理が完了しません。少し待ってから再試行してください」
が頻発する。

原因:
即時保存操作がすべて matchSaveInFlight の解除待ちになっており、
12秒待っても終わらないとユーザー操作をエラーにしていた。

V19:
- 対戦台帳の保存を直列キュー方式へ変更。
- 保存中に次の操作をしてもエラーにせず自動で次の保存へ積む。
- 120ms以内の連続操作は1回のGitHub書込へまとめる。
- 保存中に追加された変更は次バッチで自動保存。
- 紐づけ、連合設定、試合内容編集、手入力、CSV等は同じキューを共有。
- 各操作のGitHub blob照合は維持。
- GitHubの一時エラー時も変更をlocalStorageに保持し、自動再試行。
- 「少し待って再試行」のbusyエラーを廃止。
- 保存状態は
  保存待ちN件 → GitHub保存中 → 続けて保存中 → すべて保存済み
  と表示。
