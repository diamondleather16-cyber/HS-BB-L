HS-BB-L V64.3 — URL取込の登録前取捨選択・編集

1. 一括解析結果に「この大会を登録対象にする」チェックを追加。
   - 不要な大会をチェックOFFにして一括登録から除外可能。
   - 登録待ち全選択 / 全解除を追加。

2. 「試合確認」で試合単位のチェックを追加。
   - 不要な試合だけチェックOFFで登録対象から除外可能。
   - 全試合を選択 / 全解除を追加。
   - 登録対象件数をリアルタイム表示。

3. 試合内容を登録前に直接編集可能。
   - 日付 / 回戦 / 学校1 / 得点1 / 学校2 / 得点2 / イニング / 決着

4. 試合確認で行った除外・編集をブラウザに一時保存。
   - 一括結果へ戻っても保持。
   - そのまま一括登録した場合も編集済み試合リストをGitHub処理へ送る。

5. バックエンド batch_approve を拡張。
   - match_overrides を大会ごとに受け取り、選択された試合だけ登録。
   - 0試合になった大会は登録しない。

6. UI表示タグを UI-IMPORT-CURATION-V64.3 に更新。
   - CSS/JSに ?v=64.3 を付け、GitHub Pagesの旧キャッシュを避けやすくした。
